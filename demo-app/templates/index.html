Демонстрируемые flows

  • Authorization Code + PKCE — браузерный вход (/login → /callback)
  • SAML 2.0 SSO — федерация по второму протоколу (/saml/login)
  • JWE — ID token приходит зашифрованным (виден статус в кабинете)
  • WebAuthn / passkey — вход под passkey-user
  • RBAC — роли app-user / app-admin
  • Client Credentials — /api/service-token
  • JWT claims — /api/whoami
